1. Requisitos Previos

Antes de comenzar, asegúrate de tener acceso a una computadora con Windows 10 o superior. Necesitarás instalar los siguientes programas:

ProgramaVersión mínima¿Para qué sirve?
Java JDK21Lenguaje en el que está construido SIKALMA
SQL Server2019 o superiorBase de datos donde se guardan pacientes, citas, etc.
SQL Server Management Studio19 o superiorHerramienta visual para administrar la base de datos
Visual Studio CodeÚltima versiónEditor de código para abrir y ejecutar el proyecto
📌 Nota importante: NO necesitas instalar Maven. El proyecto incluye un archivo llamado mvnw.cmd (Maven Wrapper) que descarga automáticamente la versión correcta de Maven.

2. Instalar Java 21 (JDK)

  1. Descarga Java JDK 21 desde https://adoptium.net/ (Eclipse Temurin).
  2. Ejecuta el instalador y marca la opción "Set JAVA_HOME variable".
  3. Completa la instalación.
  4. Verifica que se instaló correctamente abriendo PowerShell y ejecutando:
java -version

Deberías ver algo como:

openjdk version "21.0.x" 2024-xx-xx LTS
⚠️ Si no aparece Java 21: Reinicia la computadora después de instalar Java. Si sigue sin funcionar, busca "Variables de entorno" en Windows y asegúrate de que JAVA_HOME apunte a la carpeta de instalación de Java 21.

3. Instalar y Configurar SQL Server

  1. Si ya tienes SQL Server instalado (como se ve en tu SSMS), puedes saltar este paso.
  2. Si no, descarga SQL Server 2022 Express (gratuito) desde https://www.microsoft.com/sql-server.
  3. Durante la instalación, selecciona "Basic".
  4. Después de instalar, abre SQL Server Configuration Manager.
  5. Navega a SQL Server Network Configuration → Protocols for MSSQLSERVER.
  6. Asegúrate de que TCP/IP esté habilitado.
  7. Haz doble clic en TCP/IP, ve a la pestaña "IP Addresses", y verifica que el puerto 1433 esté configurado en IPAll.
  8. Reinicia el servicio de SQL Server.
📌 Autenticación Mixta: SQL Server debe estar configurado con autenticación de modo mixto (Windows + SQL Server) para que el usuario sikalma_user pueda conectarse.

4. Crear la Base de Datos y el Usuario

Abre SQL Server Management Studio (SSMS), conéctate como sa (o cualquier cuenta administradora) y ejecuta el siguiente script:

USE master;
GO

-- Crear la base de datos (si no existe)
IF DB_ID(N'sikalma_db') IS NULL
BEGIN
    CREATE DATABASE sikalma_db;
END;
GO

-- Crear el login del usuario (si no existe)
IF SUSER_ID(N'sikalma_user') IS NULL
BEGIN
    CREATE LOGIN sikalma_user
        WITH PASSWORD = 'MiClaveSegura123',
        CHECK_POLICY = ON,
        CHECK_EXPIRATION = OFF;
END;
GO

-- Asociar el usuario a la base de datos
USE sikalma_db;
GO

IF DATABASE_PRINCIPAL_ID(N'sikalma_user') IS NULL
BEGIN
    CREATE USER sikalma_user FOR LOGIN sikalma_user;
END;
GO

-- Dar permisos necesarios
ALTER ROLE db_datareader ADD MEMBER sikalma_user;
ALTER ROLE db_datawriter ADD MEMBER sikalma_user;
ALTER ROLE db_ddladmin ADD MEMBER sikalma_user;
GO
⚠️ Importante — Cambia la contraseña: Reemplaza MiClaveSegura123 por una contraseña segura de tu elección. Recuerda esta contraseña porque la necesitarás en el paso 7.

Este script también se encuentra en el proyecto en: docs/sqlserver/00-crear-base-y-usuario.sql

5. Instalar Visual Studio Code y Extensiones

  1. Descarga VS Code desde https://code.visualstudio.com/.
  2. Instálalo con las opciones predeterminadas.
  3. Abre VS Code.
  4. Ve a la sección de Extensiones (icono de cuadrados en la barra lateral izquierda, o Ctrl+Shift+X).
  5. Busca e instala estas extensiones:
ExtensiónDescripción
Extension Pack for JavaSoporte completo para Java
Spring Boot Extension PackHerramientas para Spring Boot
Maven for JavaSoporte para Maven (se incluye con Extension Pack)
📌 Tip: Al abrir el proyecto, VS Code puede sugerir automáticamente instalar las extensiones recomendadas. Acepta la sugerencia.

6. Descomprimir y Abrir el Proyecto

  1. Localiza el archivo SIKALMA.zip.
  2. Haz clic derecho → "Extraer todo..."
  3. Elige una ubicación (ejemplo: D:\Proyecto sikalma\).
  4. Abre Visual Studio Code.
  5. Ve a Archivo → Abrir carpeta...
  6. Navega hasta la carpeta extraída y selecciona la carpeta sikalma (la que contiene pom.xml).
  7. Si VS Code pregunta "¿Confía en los autores?", haz clic en Sí.
  8. Espera 1-2 minutos a que Java y Maven importen el proyecto (verás actividad en la barra inferior).

Estructura que deberías ver en VS Code:

7. Configurar las Credenciales (.env)

Este es el paso más importante. Debes crear un archivo .env con las contraseñas locales.

  1. En VS Code, abre la terminal integrada: Terminal → Nuevo terminal (o Ctrl+Ñ).
  2. Ejecuta este comando para crear el archivo:
Copy-Item .env.example .env
  1. Abre el archivo .env que se creó (haz clic en él en el explorador de archivos de VS Code).
  2. Modifica SOLO estos dos valores:
SIKALMA_DB_HOST=localhost
SIKALMA_DB_PORT=1433
SIKALMA_DB_NAME=sikalma_db
SIKALMA_DB_USER=sikalma_user
SIKALMA_DB_PASSWORD=MiClaveSegura123        ← PON AQUÍ TU CLAVE DE SQL SERVER
SIKALMA_DB_TRUST_CERTIFICATE=true
SESSION_COOKIE_SECURE=false
SPRING_SECURITY_USER_NAME=user
SPRING_SECURITY_USER_PASSWORD=admin123      ← PON AQUÍ TU CLAVE PARA ENTRAR AL ADMIN
SPRING_SECURITY_USER_ROLES=ADMINISTRADOR
⚠️ Reglas del archivo .env:
  • SIKALMA_DB_PASSWORD debe ser la misma contraseña que usaste en el paso 4 al crear el usuario en SQL Server.
  • SPRING_SECURITY_USER_PASSWORD es la clave con la que entrarás al panel admin de SIKALMA.
  • NUNCA compartas este archivo. Está excluido del ZIP por seguridad.

8. Ejecutar el Proyecto — Método 1: F5 en VS Code (Recomendado)

  1. Presiona Ctrl+Shift+D para abrir la sección Ejecutar y Depurar.
  2. En el menú desplegable superior, selecciona "SIKALMA Desarrollo".
  3. Presiona el botón verde ▶️ o la tecla F5.
  4. Espera a que la terminal muestre el mensaje:
Started SikalmaApplication in XX seconds

¡Eso significa que la aplicación está corriendo!

9. Ejecutar el Proyecto — Método 2: Terminal PowerShell

Si el método anterior no funciona, puedes ejecutar desde la terminal:

  1. Abre una terminal en VS Code (Ctrl+Ñ).
  2. Configura las variables de entorno y ejecuta:
$env:SIKALMA_DB_PASSWORD="MiClaveSegura123"
$env:SPRING_SECURITY_USER_NAME="user"
$env:SPRING_SECURITY_USER_PASSWORD="admin123"
$env:SPRING_SECURITY_USER_ROLES="ADMINISTRADOR"
.\mvnw.cmd spring-boot:run
  1. Espera el mensaje Started SikalmaApplication.
📌 Primera ejecución: La primera vez que ejecutes el proyecto, Maven descargará todas las dependencias necesarias. Esto puede tardar 3 a 5 minutos dependiendo de la velocidad de internet. Las siguientes ejecuciones serán mucho más rápidas.

10. Abrir SIKALMA en el Navegador (localhost)

Una vez que veas el mensaje Started SikalmaApplication, abre Google Chrome (o cualquier navegador) y escribe en la barra de direcciones:

http://localhost:8080

Verás la página pública de SIKALMA con las siguientes secciones:

  • Hero con el lema del centro
  • Historia, Misión y Visión

  • Servicios (8 servicios psicológicos)

  • Equipo profesional (3 profesionales)
  • Información de contacto

Para entrar al Panel de Administración:

Escribe en el navegador:

http://localhost:8080/login

Ingresa las credenciales que configuraste en el archivo .env:

11. Usar el Panel de Administración

Después de iniciar sesión, tendrás acceso al panel administrativo con las siguientes funcionalidades:

MóduloURLFunciones
Dashboard/admin/inicioVista general con acceso a todos los módulos
Citas/admin/citasGestión de la agenda del centro
Pacientes/admin/pacientesCrear, editar y listar pacientes
Psicólogos/admin/psicologosCrear, editar y listar profesionales
Especialidades/admin/especialidadesConfigurar áreas profesionales
Servicios/admin/serviciosGestionar servicios, modalidad y duración

Ejemplo: Crear un nuevo psicólogo

  1. Haz clic en "Psicólogos" en el menú lateral.
  2. Haz clic en el botón "Nuevo psicólogo".
  3. Completa el formulario (nombres, apellidos, documento, teléfono, modalidad, especialidades).
  4. Haz clic en "Guardar".
  5. El profesional quedará registrado en la base de datos SQL Server.

Ejemplo: Crear un nuevo paciente

  1. Haz clic en "Pacientes" en el menú lateral.
  2. Haz clic en el botón "Nuevo paciente".
  3. Completa los datos (nombres, apellidos, DNI, fecha de nacimiento, teléfono, consentimiento).
  4. Haz clic en "Guardar".
  5. El paciente quedará registrado en la base de datos.
📌 Todo se guarda automáticamente: Cada vez que creas o editas un registro, los datos se guardan directamente en la base de datos sikalma_db de SQL Server. Puedes verificarlo abriendo SSMS y consultando las tablas.

12. Detener la Aplicación

  • Si usaste F5: Haz clic en el botón rojo ⬛ de la barra de depuración, o presiona Shift+F5.
  • Si usaste la terminal: Presiona Ctrl+C en la terminal donde está corriendo.

13. Solución de Problemas Comunes

❌ "Login failed for user 'sikalma_user'"

Causa: La contraseña en .env no coincide con la del usuario en SQL Server.

Solución: Abre SSMS, conéctate como sa y ejecuta:

ALTER LOGIN sikalma_user WITH PASSWORD = 'TuNuevaClaveAqui';

Luego actualiza SIKALMA_DB_PASSWORD en el archivo .env con la misma contraseña.

❌ "El puerto 8080 está ocupado"

Solución: Ejecuta en otro puerto:

$env:PORT="8081"
.\mvnw.cmd spring-boot:run

Luego abre http://localhost:8081 en el navegador.

❌ "java: command not found" o no reconoce Java

Solución: Verifica la instalación con java -version. Debe mostrar Java 21. Si no, reinstala JDK 21 desde Adoptium y reinicia la PC.

❌ VS Code no carga el proyecto Java

Solución: Presiona Ctrl+Shift+P, escribe "Java: Clean Java Language Server Workspace" y selecciónalo. Reinicia VS Code.

❌ "Cannot connect to SQL Server"

Verificaciones:

  1. El servicio de SQL Server debe estar iniciado (busca "Servicios" en Windows).
  2. TCP/IP debe estar habilitado en SQL Server Configuration Manager.
  3. El puerto debe ser 1433.
  4. La autenticación debe ser modo mixto.

❌ Usuario o contraseña incorrectos al hacer login en SIKALMA

Solución: Verifica SPRING_SECURITY_USER_NAME y SPRING_SECURITY_USER_PASSWORD en el archivo .env. Después de cambiarlos, detén y vuelve a ejecutar la aplicación.
